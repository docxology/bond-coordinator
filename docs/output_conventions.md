# Output Conventions — bond-coordinator

`output/` is the **disposable** regeneration tree.  It is gitignored,
overwritten on every run, and never hand-edited.  If a generated file is
wrong, change its generator in `src/bond_coordinator/` (or the relevant
`scripts/` orchestrator), then re-run.

## Layout

```
output/
  data/
    suite_status.json          fleet snapshot (status_report.py)
    mission_ledger.json        append-only ledger (advance_mission.py)
    manuscript_variables.json  resolved {{TOKEN}} map (z_generate_manuscript_variables.py)
    gadgets.json               optional gadget inventory input (build_situation_room.py)
    reconciled.json            film-declared codenames + gadgets (reconcile.py --write)
  situation_room.html          self-contained HTML dashboard
  manuscript/*.md              token-substituted manuscript templates
```

## Rules

- No generated file is committed; `output/` is in `.gitignore`.
- Determinism: generated bytes depend only on inputs (config + registry/ledger)
  plus the single `generated_at` timestamp — never on random draws.  Tests pin
  the clock, so repeated builds under injection are byte-identical.
- Provenance: the ledger JSON is the load-bearing audit record; treat it as
  durable, but it too can be rebuilt.

See [`output_inventory.md`](output_inventory.md) for the producer/consumer graph.
